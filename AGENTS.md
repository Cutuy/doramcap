# Agent workflow

Read the [implementation rules](docs/impl-guide.md) and [design guide](docs/design-guide.md)
before changing code; check the design guide before large features and during design review.

Use [Scanner](.agents/skills/scanner/SKILL.md) to review a PR or branch and reconcile later
